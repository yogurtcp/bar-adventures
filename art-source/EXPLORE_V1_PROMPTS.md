# Fishing and balloon adventures — generated assets

Created using the built-in imagegen tool. References are generated Bar/animal sprites from this project; the original family photograph is not included. Character sheets have three equal horizontal frames: ready, delighted, surprised. Fish occupy a three-column, two-row atlas. All generated transparency is preserved.
