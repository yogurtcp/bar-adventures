# Pancake café v1 — generated assets

Generated with the built-in imagegen tool. All character sprites preserve generated transparency. Bar’s generated food sprite was the identity reference; the existing bunny kart was an art-style reference for animals. Original family photograph is not included in this repository.

Animal sheets contain three equal frames, left to right: waiting, delighted, surprised. CSS selects these frames; pancakes are rendered natively so illustrated counts always match the question.

## bunny.png

Reference: `assets/race-v2/bunny.png`

```text
Use case: stylized-concept. Asset type: transparent pixel-art game sprite sheet. Create a cute white bunny with pink ears, matching the chunky polished pixel art of the reference. Exactly THREE equally sized square frames side by side in ONE wide 3:1 canvas. Same full-body character at identical scale, baseline and center in each frame, with transparent margins within each cell. LEFT: friendly waiting smile, eyes open, arms resting. MIDDLE: delighted, laughing, eyes happy, clapping paws or flippers. RIGHT: comically surprised, eyes wide and round mouth, paws raised. Big expressive face, appealing to a young child. True transparent background, no scenery, no panels or grid lines, no food, no table, no words. Each frame is entirely contained in its own third; generous empty margin. Reference image is style only; NO car.
```
